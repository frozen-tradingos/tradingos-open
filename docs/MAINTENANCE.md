# 维护、备份与回退

本指南只适用于你自己解压、安装的 Trading OS Open 副本。个人版、其他副本和其他程序不在操作范围内。当前没有自动升级、数据迁移或卸载工具。

## 先停机，再备份

1. 保存页面中尚未提交的内容。在运行本副本的启动窗口按 `Ctrl+C`，等待应用退出。如果回到菜单，选 **0 退出**。只关网页不能停止应用；无法确认退出时，先停止备份操作，不要按进程名称批量结束程序。
2. 用 Windows 资源管理器找到本副本的 `web/data/`，**复制整个文件夹**到自己控制的私密备份位置，按日期和版本命名。保留原件，不移动它，也不在应用运行时复制。
3. 包含全部子目录和文件，尤其是 SQLite 数据库以及存在的 `-wal`、`-shm` 文件。不要只挑 `.sqlite` 文件，不要删除你不认识的锁文件、原始证据或授权目录。
4. 同时保留这一版的原始 ZIP，以及相配套的源码、`SOURCE-MANIFEST.json`、`package.json`、两份 `pnpm-lock.yaml` 和 `requirements.txt`。记录版本、原目录和所选数据源环境，记录中不要写密钥。
5. 核对备份的文件数量、大小及复制错误提示。核对完成前保留原副本；文件复制成功仍不代表你已验证恢复可用。

`web/data/` 包含账户与交易记录、来源选择、研究历史，也可能包含 API 密钥的加密文件、模型与券商授权。请把它按敏感账户备份保管：使用离线加密介质或访问受限的位置，不上传 Git、GitHub Issues、公开网盘或公共聊天，不把整个目录当错误报告发送。

## 升级：新旧副本分开

1. 按上面的步骤停止旧副本并备份。保留旧目录和对应 ZIP，先不要覆盖、改名或删除。
2. 从[官方发行页](https://github.com/frozen-tradingos/tradingos-open/releases)下载目标版本，解压到一个新的普通目录。不要把新文件覆盖到旧目录，也不要混用不同版本的源码、依赖锁文件或源码身份清单。
3. 在新目录双击 `Start.cmd`，按提示准备本包依赖，再选 **2 设置本地密码 → 7 打开工作区**。先检查空白界面和本地登录；菜单7不调用行情或模型。旧副本须保持停止，同一时间只运行一个占用4160的副本。
4. 准备使用新副本时，重新核对自己的来源、授权和风险资料，按 [README](../README.md#连接自己的券商和数据源) 操作。检查或启用外部服务仍可能消耗你的额度；菜单8需要本次确认。

**现有数据的跨版本迁移尚未全面验收。** 当前升级路径先提供独立的新副本，不保证把旧 `data` 搬进去就兼容。需要保留历史时，先继续保留旧副本，等目标版本提供适用的迁移与恢复步骤，再用停机备份的副本验证。迁移时须保留来源选择、凭据和原始证据，不能把旧历史改标为新来源或新版结果。不要让两个版本链接、共享同一数据目录。

新记录会绑定本机源码和构建指纹；升级不会回填旧记录的身份，也不代表旧结果通过了新版验收。

## 出问题时回退

1. 停止新副本，保留它的目录与数据，避免覆盖故障证据。
2. 用**未经迁移或修改的旧副本及其旧数据**启动，先选菜单7做本地检查；需要外部研究时再核对权限并确认启用。
3. 不要用旧程序降级打开已经让新版迁移或写入的数据库，也不要将新版数据覆盖回旧目录。旧副本已损坏或已混入新版数据时，先保留原件，再请求对应版本的恢复步骤；不要反复试开唯一备份。

## 换电脑或 Windows 账号

在旧电脑停机备份，在新电脑使用完整发行包重新安装，并先按 **2 → 7** 检查空白副本。不要把旧 `.venv` 或依赖目录当成可跨路径使用的安装包。

行情、新闻密钥使用 Windows 机器级 DPAPI 加密，文件访问权限还受 NTFS 当前用户规则限制。同一台电脑换 Windows 账号也可能无法读取；跨电脑复制加密文件不能保证解密。模型、券商的登录会话也不保证可迁移。请在目标副本通过服务商官方流程重新授权，重新填写自己的密钥，不共享 Cookie、登录缓存或密钥。

历史数据的迁机恢复与跨版本迁移同样需要验证。先保留旧电脑的原件和私密备份，不把复制成功当成授权、行情或自然预测已通过。

## 卸载自己的副本

本包没有自动卸载器。使用资源管理器手工处理前：

- 停止本副本，确认需要保留的备份位于待移除目录之外，并核对具体完整路径。不要把包含其他项目或副本的上级目录当成卸载目标。
- 清点本副本的 `web/data/`、`.tools/`、`.venv/`、`web/node_modules/`、构建输出和 `_工作文件/`。本包把运行工具及可配置的下载缓存放在这些项目内目录；Windows 编译器仍会使用系统原生 TEMP/TMP。不要据此清理系统临时目录或其他软件缓存。
- 备份确认后，只将已核对的本副本目录移到回收站。不要顺带删除备份、其他副本或4070个人版，也不要按模糊目录名批量删除。
- 删除本地文件不会撤销远端授权。需要停用连接时，由你到对应服务商撤销本副本使用的 OAuth 授权、API 密钥或登录会话，核对后再操作，避免影响你仍在用的其他连接。

本文仅说明维护步骤，没有执行备份、迁移或删除，也不承诺真实授权和历史恢复已经通过验收。
