# 数据源与授权

本页列出程序会连接的服务商，供你在授权前核对。当前随包提供两条行情适配路径；新增的独立行情接口不提供券商账户连接。其他券商尚未接入。

开发者尚未完成真实新用户授权、有效行情到首个自然预测的整套验收。下表中的“已有适配”指代码与离线检查范围，不代表你的账号已经连接或拥有相关权限。

## 能力矩阵

| 服务商与环境 | 角色 | 现有只读能力 | 限制与验收状态 |
| --- | --- | --- | --- |
| Robinhood 官方 MCP | 券商账户与行情 | 已有账户、持仓、报价、K线和期权读取适配，供原有研究管线使用 | 需要本人的官方授权及接口权限；真实新用户授权和完整自然预测尚未验收。当前唯一券商账户适配 |
| Tradier Production | 独立行情 | SPY、QQQ批量报价，常规交易时段5分钟OHLCV，日线OHLCV | 新适配器通过离线合成测试。真实权限与送达未验证；不读账户、持仓、期权链、BBO、IV或Greeks，不具备完整TS与可交易计划所需能力 |
| Tradier Sandbox | 延迟行情测试 | 相同标的的报价与K线读取接口，使用独立测试密钥 | 按延迟测试证据处理，状态固定为`DATA_BLOCKED`；不生成自然预测，不计入LIVE统计，也不因时间看似新鲜而升级 |
| Finnhub，可选 | 新闻与财报 | 综合新闻、公司新闻、财报日历及服务商返回的结果字段 | 用户自备密钥；端点权限、额度和覆盖需本人验证。不是报价或K线替代源，未完成真实接入验收 |
| BLS、BEA、Federal Reserve等官方发布机构 | 宏观公告与日程 | 保留相应公开信息采集路径，按实际送达内容展示 | 选择“仅官方宏观公告”不能覆盖全部公司新闻或风险事件；采集失败、过期和缺口仍需显示 |

你选择数据源后，程序仍会检查数据时间、必要字段和研究合同。连接检查通过只证明这次读取达到了所检查的行情能力，不代表期权、持仓或完整预测已通过。

## 授权与检查步骤

1. 关闭当前应用，在 `Start.cmd` 菜单 **4 选择 / 切换行情与新闻源** 中确认服务商和环境。程序会显示授权对象。
2. 选择菜单 **5 授权当前数据源**。券商路径由你在官方页面确认；独立行情路径由你在本机隐藏输入框填写对应环境的密钥。不要将密钥发送到聊天或Issues。
3. 选择菜单 **6 本地配置检查**，查看本包配置是否齐全。它不联网，也不证明远端授权有效。
4. 准备好自己的数据权限后，选择菜单 **10 只读连接检查**。确认后程序请求SPY、QQQ行情，不调用模型。服务商可能对请求计费。
5. 查看来源、数据时间与阻断原因。只有准备使用受支持的研究路径时，才继续设置模型登录和菜单9风险档案，并从菜单 **8** 确认本次真实只读研究。

替代行情接口缺少期权和账户证据时，完整研究或计划流程会继续阻断。不要将行情连接通过理解为全功能可用。菜单8可能消耗模型额度，即使最后没有交易条件。

你保存新的来源选择后，程序会撤销旧选择的通过状态，包括切换回同一服务商的情况。请重新检查连接。程序不支持热切换；历史记录保留原来的来源。

启动器对行情和新闻API密钥使用Windows机器级DPAPI加密，先设置文件权限限制当前Windows用户，再将密钥写入本副本。机器级加密不构成密码学逐用户隔离；本机管理员仍在信任边界内。不要将凭据目录交给其他用户或同步到公开位置。

## 券商官方只读路径

当前券商适配使用 [Robinhood官方Trading MCP](https://agent.robinhood.com/mcp/trading)。你需要在服务商的官方流程中授权自己的账号。程序使用只读工具白名单，不提供下单、撤单或自动跟单执行。

程序将本包的模型登录与券商授权分开保存，不继承全局或其他项目的登录。菜单5的授权命令完成，仅表示本地步骤结束；后续读取仍可能因权限过期、账号资格或接口覆盖而失败。

其他券商需要各自的官方接口、适配和验收。此版本没有通用多券商账户连接，也没有接入聚合券商服务。

## 独立行情API

Tradier适配只允许`GET`请求，固定访问以下官方端点：

| 用途 | 路径 |
| --- | --- |
| SPY、QQQ批量报价 | `/v1/markets/quotes` |
| 常规时段5分钟K线 | `/v1/markets/timesales`，`interval=5min`，`session_filter=open` |
| 日线K线 | `/v1/markets/history`，`interval=daily` |

Production使用`api.tradier.com`，Sandbox使用`sandbox.tradier.com`，两种环境的密钥不能混用。程序不接受自填API主机，不跟随重定向，不请求交易或账户端点。官方资料：[环境与端点](https://docs.tradier.com/docs/endpoints)、[行情权限与延迟](https://docs.tradier.com/docs/market-data)。

适配器保留服务商报价时间和5分钟区间时间，只接纳完成的常规交易K线。日线索引保留服务商的交易日日期，不能用作实时报价时间。周末读取最近完成的交易日时，程序保留原时间，不把旧数据改成当前时间。

Tradier官方将Sandbox行情定义为延迟数据。程序把Sandbox用于连接测试，禁止将它标为LIVE。Production标签也不证明你的账号有实时权限；请核对本人的授权、数据质量和[服务商使用说明](https://docs.tradier.com/docs/faq)。开源代码不授予数据公开分发权限。

本次新增适配不采集期权链、可执行BBO、IV、Greeks或期权历史，相应能力保持不可用。它不会用股票报价生成虚拟期权，也不会将行情密钥冒充券商账户授权。

## 可选新闻与财报

在菜单4中选择新闻API后，使用菜单 **11 配置所选新闻源密钥**。Finnhub提供API服务，不需要另装客户端、插件或SDK。请通过[官方网站](https://finnhub.io/)查看自己账号的[套餐与权限](https://finnhub.io/pricing)，不要为了安装本项目购买套餐。

现有适配请求`/news`、`/company-news`和`/calendar/earnings`。某一接口可用，不代表其他接口、实时数据或商业展示权限也可用。401/403需核对密钥及端点权限，429需核对额度；程序不会据此替你升级付费套餐。

不需要新闻API时，可在菜单4选择“仅官方宏观公告”或“不接新闻”。公开宏观公告不能替代公司新闻与财报覆盖；缺失新闻不能证明没有风险事件。

菜单11在本机隐藏输入密钥，采用上述Windows机器级加密和当前用户文件权限保护。菜单6只确认本地配置，菜单10检查行情，不验证新闻端点。真实新闻送达、权限和覆盖仍需按所选路径验收。

将新闻、行情或派生结果发送给模型服务或展示给他人前，请核对服务条款。不要共用密钥或公开上传服务商数据。参考[Finnhub服务条款](https://finnhub.io/terms-of-service)，具体许可与费用由服务商和你的账号决定。

## 费用与反馈

MIT许可覆盖本项目源码。第三方模型、券商和数据服务保留各自的授权与计费规则，免费额度也可能附带用途限制。本项目不附带账号、不代开套餐，目前没有付费解锁入口。

遇到错误时，先记录当前版本、选择的服务商和环境，以及脱敏后的错误文字。通过[GitHub Issues](https://github.com/frozen-tradingos/tradingos-open/issues)反馈；不要附密钥、授权链接、持仓或订单原文。
