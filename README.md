# Trading OS Open

Trading OS Open 是在自己电脑运行的开源交易研究工具，附带研究助手 Skill。你使用自己的模型账号、券商账号和数据权限，检查预测依据，记录交易计划并复盘。

**Windows 10/11 x64 · 只读研究 · MIT · v0.1.0-preview.5**

[下载预览版](https://github.com/frozen-tradingos/tradingos-open/releases/tag/v0.1.0-preview.5) · [首次安装](#首次安装) · [数据源与授权](docs/PROVIDERS.md) · [升级与备份](docs/MAINTENANCE.md) · [反馈问题](https://github.com/frozen-tradingos/tradingos-open/issues/new/choose)

## 项目定位

本项目公开程序源码和 Skill，供你在本机部署、配置和扩展。发布包不附带作者的私人数据、持仓、账号或密钥，也不提供第三方行情订阅、账户托管或代接券商服务。

你自行选择券商、行情和新闻服务，并完成开户、授权及权限核对。随包已有适配器只提供文档列出的能力；其他服务需要你自行开发或委托开发适配器，再验证接入。本项目不承诺逐家接入或验证全球券商和数据源。

## 用它做什么

- **研究预测**：查看 TS 的市场判断、目标交易日和依据，区分次日观察与当前交易条件。
- **核对计划**：查看触发条件、失效条件和风险限制；证据不足时保留未就绪状态。
- **记录与复盘**：写下自己的交易理由，对照原始预测和后续市场记录，不覆盖旧判断。
- **管理本地研究环境**：选择已有适配的行情和新闻源，查看连接状态；数据与授权留在当前副本。

当前是实验预览版。开发者用合成数据测试接口和研究流程，尚未完成真实新用户授权、有效行情到首个自然预测的整套验收。软件提供研究参考，不提供自动下单或跟单执行，不保证预测准确或盈利。

Open-source, local-first market research, TS forecasts, trading plans and reviews. Bring your own accounts and data permissions. Use the documented adapters or implement and validate your own integration. Windows x64 preview; live authorization and a first natural forecast remain unverified end to end.

## 首次安装

1. 从[发行页](https://github.com/frozen-tradingos/tradingos-open/releases/tag/v0.1.0-preview.5)下载 `TradingOS-Open-v0.1.0-preview.5.zip`，完整解压到自己的普通文件夹，例如 `D:\02_项目\TradingOS-Open`。与已有 Trading OS 副本分开放置，不链接旧数据目录。
2. 双击 `Start.cmd`。首次运行会请求下载许可；输入 `DOWNLOAD` 后，启动器下载并校验固定版本的运行工具，安装锁定依赖，再构建界面。工具保存在本包 `.tools/`，不要求你先安装全局开发工具。
3. 进入菜单后，选择 **2 设置本地登录密码**，再选 **7 打开工作区**。在 `http://127.0.0.1:4160` 使用 `owner` 和自己的本地密码登录。这里不需要项目的云账号或邮件登录；菜单7不请求行情或模型分析。
4. 准备连接服务时，按下表完成自己的授权、连接检查和风险资料。授权页要求开户、充值、扩大权限或购买套餐时，先停止并核对费用。

首次下载需要网络。工具或依赖校验失败时，启动器会停止准备；重试前先看错误提示。离线工作区不会因此自动接管其他程序或端口。

### 连接自己的券商和数据源

只查看界面，按 **2 → 7** 操作即可，不需要券商或模型账号。准备使用随包现有研究路径时，按 **2 → 3 → 4 → 5 → 9 → 6 → 10 → 8** 完成自己的模型登录、来源选择、授权及检查。新闻源需要密钥时，在菜单4选择后使用菜单11。菜单1用于安装或修复依赖。

授权由你在服务商的官方流程中完成；API密钥只填入本机隐藏输入框，不发给项目维护者。保存配置或完成登录命令不代表远端连接成功。菜单6只检查本地配置；菜单10只检查所选来源的SPY、QQQ报价与K线，不验证新闻、持仓、期权或完整预测。

菜单4没有你的服务商时，请先完成适配开发，不要把其他服务的密钥填进现有选项。现有菜单不接受任意API地址，也没有通用券商或通用模型API连接器。模型登录按菜单3的现有流程进行，其他模型路径同样需要自行适配。

菜单8会启用研究流程。即使最终没有交易条件，模型也可能消耗额度。先查看菜单10的行情来源与时间，再决定是否启用。研究页只展示自然时段实际产生的结果；休市、权限不足或缺少必要数据时，流程可能继续阻断。

## 数据源与支持范围

你可以分别选择行情和新闻来源。券商账户连接负责读取持仓，独立行情接口负责提供报价与K线，两者的权限不同。新增行情源不等于新增券商账户支持。

[数据源与授权说明](docs/PROVIDERS.md)列出了服务商名称、接口范围和未完成的验收项目。请在授权前阅读。当前只提供已有适配器的选项，不能填入任意 API 地址后通用接入。

“已有适配”表示随包有对应代码，不表示你已获得授权或开发者已完成真实接入验收。真实新用户授权到首次自然预测仍未完整验证；新增独立行情适配只读取基础报价和K线，缺少账户与期权证据，不能完成完整TS或期权计划流程。合成测试和界面检查不能证明真实预测准确率。

切换前先关闭应用，回到菜单4保存新选择，再授权并运行菜单10。新选择会使旧来源的通过状态失效；程序不支持运行中的热切换，也不会把原有历史改成新来源。

| 部分 | 当前范围 |
| --- | --- |
| 总览、市场、持仓、研究与复盘界面 | 本地工作区；新副本不带个人历史 |
| TS预测与条件研究 | 保留现有分析、复核和风控合同；需要完整且有效的证据 |
| 行情源选择 | 已有券商行情路径与新增独立行情接口，能力不同，详见接入说明 |
| 其他券商账户 | 尚未接入；不承诺通用多券商连接 |
| 新闻与财报 | 可选，覆盖与权限需本人检查；空白不代表没有风险事件 |
| 下单与执行 | 不提供，程序禁止券商写操作 |
| 云账号、邮件注册、收款与域名 | 不属于本包的安装流程 |

## 费用与数据安全

你可以按 MIT 许可使用本项目源码。本项目未开放订阅、付费解锁或收款入口。模型、行情和券商服务各自规定费用与权限，开源许可不包含这些服务。不要为了安装本包购买套餐；先确认自己已有的权限，遇到收费再作决定。

自动研究会将相关市场或账户证据发送给你选择的模型服务。请先核对数据许可和隐私要求，不多人共用密钥，也不把第三方数据上传到公开仓库。

- 本副本将运行数据保存在 `web/data/`，将模型和券商授权分开保存，不继承其他项目的登录。
- 行情和新闻API密钥采用Windows机器级加密，文件权限限制当前用户；这不构成密码学逐用户隔离，本机管理员仍需受信任。
- 新库从空白开始，不预置他人的持仓、本金或风险限额。菜单9只创建本人第一版档案，后续修改需要追加版本流程。
- 请勿把数据目录同步到公开网盘，或在聊天、截图、Issues中发送密钥、验证码、授权链接及账户记录。
- 你按 `Ctrl+C` 结束启动器后，程序会关闭本副本的应用子进程，不按名称终止其他软件。

新预测记录会绑定本机源码和构建指纹，旧记录不回填升级。这个检查只核对本机内容与记录一致性，不认证发布者、安全性、实际模型调用或预测优势。

升级前先阅读[维护、备份与回退指南](docs/MAINTENANCE.md)，停机后备份本副本的整个 `web/data/`。新版本解压到新目录；跨版本数据迁移尚未全面验收，不要覆盖旧副本或让两个版本共用数据。

## 随包 Skill

`.agents/skills/tradingos-research/` 提供研究助手指引。在 Codex 中打开本项目后，可以说“检查准备状态”或“按原始证据复盘这次计划”。助手需要先检查来源和权限；它不能代替环境安装或第三方授权，也不能把示例写成真实结果。

